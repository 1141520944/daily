# 堆

## 一、基础概念

堆（Heap）是一种特殊的完全二叉树，特点：
- **完全二叉树**：除了最后一层，其他层都是满的
- **堆性质**：
  - **最大堆**：父节点 ≥ 子节点，根节点是最大值
  - **最小堆**：父节点 ≤ 子节点，根节点是最小值
- **常用操作**：插入 O(log n)、删除堆顶 O(log n)、获取堆顶 O(1)

### Go 语言中的堆

Go 标准库提供了 `container/heap` 接口，需要实现以下方法：

```go
import "container/heap"

type IntHeap []int

func (h IntHeap) Len() int           { return len(h) }
func (h IntHeap) Less(i, j int) bool { return h[i] < h[j] } // 最小堆
func (h IntHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }

func (h *IntHeap) Push(x interface{}) {
    *h = append(*h, x.(int))
}

func (h *IntHeap) Pop() interface{} {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[:n-1]
    return x
}

// 使用示例
h := &IntHeap{2, 1, 5}
heap.Init(h)        // 初始化堆
heap.Push(h, 3)     // 插入元素
min := heap.Pop(h)  // 弹出最小值
```

## 二、常见题型分类

### 1. Top K 问题

**适用场景**：
- 数组中的第 K 个最大元素
- 前 K 个高频元素
- 数据流中的第 K 大元素
- 最小的 K 个数

**核心思想**：
- 维护一个大小为 K 的堆
- 最小堆找第 K 大，最大堆找第 K 小

#### 示例1：数组中的第 K 个最大元素（LeetCode 215）

```go
import "container/heap"

type MinHeap []int

func (h MinHeap) Len() int           { return len(h) }
func (h MinHeap) Less(i, j int) bool { return h[i] < h[j] }
func (h MinHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }

func (h *MinHeap) Push(x interface{}) {
    *h = append(*h, x.(int))
}

func (h *MinHeap) Pop() interface{} {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[:n-1]
    return x
}

func findKthLargest(nums []int, k int) int {
    h := &MinHeap{}
    heap.Init(h)
    
    for _, num := range nums {
        heap.Push(h, num)
        if h.Len() > k {
            heap.Pop(h) // 保持堆大小为 k
        }
    }
    
    return (*h)[0] // 堆顶就是第 K 大元素
}
```

**解题思路**：
1. 维护一个大小为 K 的最小堆
2. 遍历数组，将元素加入堆
3. 如果堆大小超过 K，弹出最小值
4. 最后堆顶就是第 K 大的元素

**时间复杂度**：O(n log k)，空间复杂度：O(k)

#### 示例2：前 K 个高频元素（LeetCode 347）

```go
func topKFrequent(nums []int, k int) []int {
    // 统计频率
    freqMap := make(map[int]int)
    for _, num := range nums {
        freqMap[num]++
    }
    
    // 使用最小堆维护前 K 个高频元素
    type Pair struct {
        num  int
        freq int
    }
    
    h := &MinHeapPair{}
    heap.Init(h)
    
    for num, freq := range freqMap {
        heap.Push(h, Pair{num, freq})
        if h.Len() > k {
            heap.Pop(h)
        }
    }
    
    result := []int{}
    for h.Len() > 0 {
        result = append(result, heap.Pop(h).(Pair).num)
    }
    
    return result
}

type MinHeapPair []Pair

type Pair struct {
    num  int
    freq int
}

func (h MinHeapPair) Len() int           { return len(h) }
func (h MinHeapPair) Less(i, j int) bool { return h[i].freq < h[j].freq }
func (h MinHeapPair) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }

func (h *MinHeapPair) Push(x interface{}) {
    *h = append(*h, x.(Pair))
}

func (h *MinHeapPair) Pop() interface{} {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[:n-1]
    return x
}
```

**解题思路**：
1. 用哈希表统计每个元素的频率
2. 用最小堆维护前 K 个高频元素
3. 按频率比较，堆顶是频率最小的

### 2. 合并 K 个有序序列

**适用场景**：
- 合并 K 个升序链表
- 合并 K 个排序数组
- 多路归并

**核心思想**：
- 用最小堆维护 K 个序列的当前最小值
- 每次取出最小值，然后将该序列的下一个元素加入堆

#### 示例：合并 K 个升序链表（LeetCode 23）

```go
func mergeKLists(lists []*ListNode) *ListNode {
    h := &MinHeapNode{}
    heap.Init(h)
    
    // 将所有链表的头节点加入堆
    for _, list := range lists {
        if list != nil {
            heap.Push(h, list)
        }
    }
    
    dummy := &ListNode{}
    curr := dummy
    
    for h.Len() > 0 {
        // 取出最小节点
        node := heap.Pop(h).(*ListNode)
        curr.Next = node
        curr = curr.Next
        
        // 如果该节点有下一个，加入堆
        if node.Next != nil {
            heap.Push(h, node.Next)
        }
    }
    
    return dummy.Next
}

type MinHeapNode []*ListNode

func (h MinHeapNode) Len() int           { return len(h) }
func (h MinHeapNode) Less(i, j int) bool { return h[i].Val < h[j].Val }
func (h MinHeapNode) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }

func (h *MinHeapNode) Push(x interface{}) {
    *h = append(*h, x.(*ListNode))
}

func (h *MinHeapNode) Pop() interface{} {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[:n-1]
    return x
}
```

**解题思路**：
1. 将所有链表的头节点加入最小堆
2. 每次取出堆顶（最小值），连接到结果链表
3. 如果取出的节点有下一个节点，将其加入堆
4. 重复直到堆为空

**时间复杂度**：O(N log k)，其中 N 是所有节点总数，k 是链表数量

### 3. 数据流中的中位数

**适用场景**：
- 数据流的中位数
- 滑动窗口中位数
- 动态维护中位数

**核心思想**：
- 用两个堆：最大堆存储较小的一半，最小堆存储较大的一半
- 保持两个堆的大小平衡

#### 示例：数据流的中位数（LeetCode 295）

```go
type MedianFinder struct {
    maxHeap *MaxHeap // 存储较小的一半
    minHeap *MinHeap // 存储较大的一半
}

func Constructor() MedianFinder {
    maxH := &MaxHeap{}
    minH := &MinHeap{}
    heap.Init(maxH)
    heap.Init(minH)
    
    return MedianFinder{
        maxHeap: maxH,
        minHeap: minH,
    }
}

func (this *MedianFinder) AddNum(num int) {
    // 先加入最大堆
    heap.Push(this.maxHeap, num)
    
    // 将最大堆的最大值移到最小堆
    maxVal := heap.Pop(this.maxHeap).(int)
    heap.Push(this.minHeap, maxVal)
    
    // 保持平衡：最小堆的大小不能超过最大堆
    if this.minHeap.Len() > this.maxHeap.Len() {
        minVal := heap.Pop(this.minHeap).(int)
        heap.Push(this.maxHeap, minVal)
    }
}

func (this *MedianFinder) FindMedian() float64 {
    if this.maxHeap.Len() == this.minHeap.Len() {
        return float64((*this.maxHeap)[0]+(*this.minHeap)[0]) / 2.0
    }
    return float64((*this.maxHeap)[0])
}

// 最大堆
type MaxHeap []int

func (h MaxHeap) Len() int           { return len(h) }
func (h MaxHeap) Less(i, j int) bool { return h[i] > h[j] } // 注意这里是 >
func (h MaxHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }

func (h *MaxHeap) Push(x interface{}) {
    *h = append(*h, x.(int))
}

func (h *MaxHeap) Pop() interface{} {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[:n-1]
    return x
}

// 最小堆
type MinHeap []int

func (h MinHeap) Len() int           { return len(h) }
func (h MinHeap) Less(i, j int) bool { return h[i] < h[j] }
func (h MinHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }

func (h *MinHeap) Push(x interface{}) {
    *h = append(*h, x.(int))
}

func (h *MinHeap) Pop() interface{} {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[:n-1]
    return x
}
```

**解题思路**：
1. 最大堆存储较小的一半数据
2. 最小堆存储较大的一半数据
3. 保持两个堆的大小差不超过 1
4. 中位数要么是堆顶，要么是两个堆顶的平均值

### 4. 优先队列应用

**适用场景**：
- Dijkstra 最短路径算法
- Prim 最小生成树算法
- 任务调度
- Huffman 编码

#### 示例：最后一块石头的重量（LeetCode 1046）

```go
func lastStoneWeight(stones []int) int {
    h := &MaxHeap{}
    heap.Init(h)
    
    for _, stone := range stones {
        heap.Push(h, stone)
    }
    
    for h.Len() > 1 {
        y := heap.Pop(h).(int) // 最重的
        x := heap.Pop(h).(int) // 第二重的
        
        if x != y {
            heap.Push(h, y-x) // 差值重新加入
        }
    }
    
    if h.Len() == 0 {
        return 0
    }
    return heap.Pop(h).(int)
}
```

## 三、解题通用步骤

### Step 1: 识别问题类型
- Top K 问题 → 堆
- 合并多个有序序列 → 堆
- 动态维护最值 → 堆
- 贪心算法需要每次都取最值 → 堆

### Step 2: 选择堆的类型
| 问题需求 | 堆类型 |
|---------|--------|
| 第 K 大元素 | 最小堆（大小 K） |
| 第 K 小元素 | 最大堆（大小 K） |
| 前 K 个最大 | 最小堆（大小 K） |
| 前 K 个最小 | 最大堆（大小 K） |
| 中位数 | 最大堆 + 最小堆 |
| 合并 K 个有序 | 最小堆 |

### Step 3: 设计堆的比较逻辑
- 实现 `Less` 方法定义优先级
- 最小堆：`h[i] < h[j]`
- 最大堆：`h[i] > h[j]`

### Step 4: 维护堆的大小
- Top K 问题：保持堆大小为 K
- 合并问题：动态添加和删除

## 五、常见陷阱与注意事项

1. **堆的类型**：搞清楚是用最小堆还是最大堆
2. **Less 方法**：最大堆用 `>`，最小堆用 `<`
3. **空堆检查**：Pop 前确保堆不为空
4. **自定义结构**：实现完整的 heap.Interface 接口
5. **性能考虑**：频繁插入删除时，堆比排序更高效

## 六、Go 语言堆的技巧

```go
// 1. 最小堆模板
type MinHeap []int

func (h MinHeap) Len() int           { return len(h) }
func (h MinHeap) Less(i, j int) bool { return h[i] < h[j] }
func (h MinHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }
func (h *MinHeap) Push(x interface{}) { *h = append(*h, x.(int)) }
func (h *MinHeap) Pop() interface{} {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[:n-1]
    return x
}

// 2. 最大堆模板（只需改 Less）
type MaxHeap []int

func (h MaxHeap) Len() int           { return len(h) }
func (h MaxHeap) Less(i, j int) bool { return h[i] > h[j] } // 注意这里
func (h MaxHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }
func (h *MaxHeap) Push(x interface{}) { *h = append(*h, x.(int)) }
func (h *MaxHeap) Pop() interface{} {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[:n-1]
    return x
}

// 3. 自定义结构体堆
type Item struct {
    value    int
    priority int
}

type PriorityQueue []*Item

func (pq PriorityQueue) Len() int { return len(pq) }
func (pq PriorityQueue) Less(i, j int) bool {
    return pq[i].priority > pq[j].priority // 高优先级先出
}
func (pq PriorityQueue) Swap(i, j int) {
    pq[i], pq[j] = pq[j], pq[i]
}
func (pq *PriorityQueue) Push(x interface{}) {
    *pq = append(*pq, x.(*Item))
}
func (pq *PriorityQueue) Pop() interface{} {
    old := *pq
    n := len(old)
    item := old[n-1]
    *pq = old[:n-1]
    return item
}

// 4. 使用示例
pq := &PriorityQueue{}
heap.Init(pq)
heap.Push(pq, &Item{value: 1, priority: 10})
item := heap.Pop(pq).(*Item)
```

## 七、堆 vs 其他数据结构

| 操作 | 堆 | 排序数组 | 平衡树 |
|------|-----|---------|--------|
| 获取最值 | O(1) | O(1) | O(log n) |
| 插入 | O(log n) | O(n) | O(log n) |
| 删除最值 | O(log n) | O(n) | O(log n) |
| 查找任意元素 | O(n) | O(log n) | O(log n) |
| 动态维护 | ✅ | ❌ | ✅ |

**选择建议**：
- 只需要最值 → 堆
- 需要查找任意元素 → 平衡树或哈希表
- 静态数据 → 排序数组
