# 哈希表

## 一、基础概念

哈希表（Hash Table）是一种基于键值对的数据结构，特点：
- **快速查找**：平均 O(1) 时间复杂度
- **键值映射**：通过 key 快速访问 value
- **空间换时间**：用额外空间换取查询效率
- **哈希冲突**：多个 key 映射到同一位置时需要处理

### Go 语言中的哈希表

```go
// 创建 map
m := make(map[string]int)
m["key"] = 10

// 访问元素
val, exists := m["key"]
if exists {
    fmt.Println(val)
}

// 删除元素
delete(m, "key")

// 遍历
for k, v := range m {
    fmt.Printf("%s: %d\n", k, v)
}
```

## 二、常见题型分类

### 1. 查找与存在性判断

**适用场景**：
- 两数之和
- 判断元素是否存在
- 寻找重复元素
- 集合运算（交集、并集）

**核心思想**：
- 将查找从 O(n) 优化到 O(1)
- 用空间换时间

#### 示例1：两数之和（LeetCode 1）

```go
func twoSum(nums []int, target int) []int {
    // map[value]index
    numMap := make(map[int]int)
    
    for i, num := range nums {
        complement := target - num
        if j, ok := numMap[complement]; ok {
            return []int{j, i}
        }
        numMap[num] = i
    }
    
    return []int{}
}
```

**解题思路**：
1. 遍历数组，对于每个数 `num`，计算需要的补数 `complement = target - num`
2. 检查补数是否已经在 map 中
3. 如果存在，返回两个索引；否则将当前数加入 map

#### 示例2：存在重复元素（LeetCode 217）

```go
func containsDuplicate(nums []int) bool {
    seen := make(map[int]bool)
    
    for _, num := range nums {
        if seen[num] {
            return true
        }
        seen[num] = true
    }
    
    return false
}
```

### 2. 计数与统计

**适用场景**：
- 统计元素出现次数
- 寻找多数元素
- 字母异位词分组
- 最长连续序列

**核心思想**：
- 用 map 记录每个元素的出现次数
- 根据计数结果进行后续处理

#### 示例1：字母异位词分组（LeetCode 49）

```go
func groupAnagrams(strs []string) [][]string {
    groups := make(map[string][]string)
    
    for _, str := range strs {
        // 将字符串排序作为 key
        chars := []rune(str)
        sort.Slice(chars, func(i, j int) bool {
            return chars[i] < chars[j]
        })
        key := string(chars)
        
        groups[key] = append(groups[key], str)
    }
    
    result := [][]string{}
    for _, group := range groups {
        result = append(result, group)
    }
    
    return result
}
```

**解题思路**：
1. 字母异位词排序后相同
2. 用排序后的字符串作为 key
3. 将原字符串分组存储

#### 示例2：最长连续序列（LeetCode 128）

```go
func longestConsecutive(nums []int) int {
    if len(nums) == 0 {
        return 0
    }
    
    // 将所有数字放入 set
    numSet := make(map[int]bool)
    for _, num := range nums {
        numSet[num] = true
    }
    
    maxLen := 0
    
    for num := range numSet {
        // 只有当 num-1 不存在时，num 才可能是序列起点
        if !numSet[num-1] {
            currentNum := num
            currentLen := 1
            
            // 向后延伸
            for numSet[currentNum+1] {
                currentNum++
                currentLen++
            }
            
            if currentLen > maxLen {
                maxLen = currentLen
            }
        }
    }
    
    return maxLen
}
```

**解题思路**：
1. 将所有数字放入哈希集合
2. 只从序列的起点开始计数（避免重复计算）
3. 向后延伸找到完整序列长度

### 3. 缓存与记忆化

**适用场景**：
- LRU 缓存
- 斐波那契数列（记忆化搜索）
- 动态规划优化

**核心思想**：
- 存储已计算的结果
- 避免重复计算

#### 示例：LRU 缓存（LeetCode 146）

```go
type LRUCache struct {
    capacity int
    cache    map[int]*DoublyListNode
    head     *DoublyListNode
    tail     *DoublyListNode
}

type DoublyListNode struct {
    key, val int
    prev, next *DoublyListNode
}

func Constructor(capacity int) LRUCache {
    head := &DoublyListNode{}
    tail := &DoublyListNode{}
    head.next = tail
    tail.prev = head
    
    return LRUCache{
        capacity: capacity,
        cache:    make(map[int]*DoublyListNode),
        head:     head,
        tail:     tail,
    }
}

func (this *LRUCache) Get(key int) int {
    if node, ok := this.cache[key]; ok {
        this.moveToHead(node)
        return node.val
    }
    return -1
}

func (this *LRUCache) Put(key int, value int) {
    if node, ok := this.cache[key]; ok {
        node.val = value
        this.moveToHead(node)
    } else {
        newNode := &DoublyListNode{key: key, val: value}
        this.cache[key] = newNode
        this.addToHead(newNode)
        
        if len(this.cache) > this.capacity {
            removed := this.removeTail()
            delete(this.cache, removed.key)
        }
    }
}

func (this *LRUCache) addToHead(node *DoublyListNode) {
    node.prev = this.head
    node.next = this.head.next
    this.head.next.prev = node
    this.head.next = node
}

func (this *LRUCache) removeNode(node *DoublyListNode) {
    node.prev.next = node.next
    node.next.prev = node.prev
}

func (this *LRUCache) moveToHead(node *DoublyListNode) {
    this.removeNode(node)
    this.addToHead(node)
}

func (this *LRUCache) removeTail() *DoublyListNode {
    node := this.tail.prev
    this.removeNode(node)
    return node
}
```

### 4. 前缀和 + 哈希表

**适用场景**：
- 和为 K 的子数组
- 连续数组（0 和 1 数量相等）
- 矩阵区域和

**核心思想**：
- 记录前缀和出现的次数
- 利用 `prefix[j] - prefix[i] = k` 的性质

#### 示例：和为 K 的子数组（LeetCode 560）

```go
func subarraySum(nums []int, k int) int {
    // map[prefix_sum]count
    prefixCount := map[int]int{0: 1}
    prefixSum := 0
    count := 0
    
    for _, num := range nums {
        prefixSum += num
        
        // 如果存在 prefixSum - k，说明有子数组和为 k
        if cnt, ok := prefixCount[prefixSum-k]; ok {
            count += cnt
        }
        
        prefixCount[prefixSum]++
    }
    
    return count
}
```

**解题思路**：
1. 维护当前前缀和
2. 如果之前出现过 `prefixSum - k`，说明存在子数组和为 k
3. 累加所有可能的组合数

## 三、解题通用步骤

### Step 1: 识别问题特征
- 需要快速查找？ → 哈希表
- 需要统计频次？ → map[value]count
- 需要去重？ → map[value]bool 或 set
- 需要映射关系？ → map[key]value

### Step 2: 设计 Key 和 Value
| 问题类型 | Key | Value |
|---------|-----|-------|
| 查找存在性 | 元素值 | bool / index |
| 计数统计 | 元素值 | count |
| 分组问题 | 标准化后的值 | []original |
| 前缀和 | 前缀和 | count / index |

### Step 3: 选择遍历策略
- 一次遍历：边查边存（如两数之和）
- 两次遍历：先存后查（如存在重复元素）
- 多次遍历：复杂统计（如分组问题）

### Step 4: 处理边界情况
- 空输入
- 找不到目标
- 多个答案的情况

## 五、常见陷阱与注意事项

1. **Key 的类型**：Go 中 map 的 key 必须是可比较的类型
2. **切片不能作为 key**：需要转换为字符串或其他可比较类型
3. **遍历顺序不确定**：Go 的 map 遍历顺序是随机的
4. **并发安全**：普通 map 不是线程安全的，并发时使用 `sync.Map`
5. **内存泄漏**：及时删除不需要的键值对

```go
// 1. 初始化带容量的 map（性能优化）
m := make(map[string]int, 100)

// 2. 安全访问
if val, ok := m[key]; ok {
    // key 存在

    // key 不存在

// 3. 使用 struct 作为 key
type Point struct {
    X, Y int

// 4. 嵌套 map

    // 1 在集合中
}

// 6. 批量删除

    }
```

## 七、哈希表 vs 其他数据结构

| 操作 | 哈希表 | 数组 | 平衡树 |
|------|--------|------|--------|
| 查找 | O(1) | O(n) | O(log n) |
| 插入 | O(1) | O(n) | O(log n) |
| 删除 | O(1) | O(n) | O(log n) |
| 有序遍历 | ❌ | ✅ | ✅ |
| 范围查询 | ❌ | ✅ | ✅ |
| 最值查询 | O(n) | O(n) | O(log n) |

**选择建议**：
- 只需要快速查找 → 哈希表
- 需要有序性或范围查询 → 平衡树（Go 中没有内置，需第三方库）
- 数据量小且连续 → 数组
