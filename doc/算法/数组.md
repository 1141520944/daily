# 数组

## 一、数组基础概念

数组是最基本的数据结构之一，特点：
- **连续内存存储**：元素在内存中连续存放
- **随机访问**：通过索引 O(1) 时间访问任意元素
- **固定大小**（静态数组）或**动态扩容**（动态数组）
- **插入/删除效率低**：需要移动元素，O(n) 时间复杂度

## 二、常见题型分类

### 1. 双指针法（Two Pointers）

**适用场景**：
- 有序数组去重
- 数组元素移除
- 两数之和（有序数组）
- 合并有序数组

**核心思想**：
- **快慢指针**：一个指针遍历，一个指针记录有效位置
- **左右指针**：从两端向中间逼近

#### 示例1：删除有序数组中的重复项（LeetCode 26）

```go
func removeDuplicates(nums []int) int {
    if len(nums) == 0 {
        return 0
    }
    
    slow := 1 // 慢指针指向下一个要填充的位置
    for fast := 1; fast < len(nums); fast++ {
        // 当前元素与前一个不同，说明是新元素
        if nums[fast] != nums[fast-1] {
            nums[slow] = nums[fast]
            slow++
        }
    }
    return slow
}
```

**解题思路**：
1. 慢指针 `slow` 指向下一个不重复元素应该放置的位置
2. 快指针 `fast` 遍历数组寻找新元素
3. 当发现新元素时，将其放到 `slow` 位置，`slow` 前进一步

#### 示例2：移除元素（LeetCode 27）

```go
func removeElement(nums []int, val int) int {
    slow := 0
    for fast := 0; fast < len(nums); fast++ {
        if nums[fast] != val {
            nums[slow] = nums[fast]
            slow++
        }
    }
    return slow
}
```

**解题思路**：
1. 快指针遍历所有元素
2. 遇到不等于 `val` 的元素，复制到慢指针位置
3. 慢指针只在不等于 `val` 时前进

### 2. 滑动窗口（Sliding Window）

**适用场景**：
- 连续子数组问题
- 最小/最大长度子数组
- 满足某条件的子数组

**核心思想**：
- 维护一个窗口 `[left, right]`
- 右指针扩展窗口，左指针收缩窗口
- 在窗口满足条件时更新答案

#### 示例：长度最小的子数组（LeetCode 209）

```go
func minSubArrayLen(target int, nums []int) int {
    n := len(nums)
    if n == 0 {
        return 0
    }
    
    left, right := 0, 0
    sum := 0
    minLen := math.MaxInt32
    
    for right < n {
        sum += nums[right] // 扩大窗口
        
        // 当窗口满足条件时，尝试收缩
        for sum >= target {
            if right-left+1 < minLen {
                minLen = right - left + 1
            }
            sum -= nums[left] // 缩小窗口
            left++
        }
        right++
    }
    
    if minLen == math.MaxInt32 {
        return 0
    }
    return minLen
}
```

**解题模板**：
```go
left, right := 0, 0
for right < len(nums) {
    // 1. 扩大窗口：将 right 加入窗口
    window.add(nums[right])
    right++
    
    // 2. 判断是否需要收缩窗口
    for window.needsShrink() {
        // 3. 更新答案
        updateAnswer()
        
        // 4. 缩小窗口：将 left 移出窗口
        window.remove(nums[left])
        left++
    }
}
```

### 3. 哈希表法

**适用场景**：
- 查找元素是否存在
- 统计元素出现次数
- 两数之和
- 寻找重复元素

**核心思想**：
- 用空间换时间，将查找从 O(n) 降到 O(1)
- 常见操作：计数、去重、映射

#### 示例：多数元素（LeetCode 169）

```go
// 方法1：哈希表计数
func majorityElement(nums []int) int {
    count := make(map[int]int)
    half := len(nums) / 2
    
    for _, num := range nums {
        count[num]++
        if count[num] > half {
            return num
        }
    }
    return -1
}

// 方法2：Boyer-Moore 投票算法（最优解）
func majorityElement(nums []int) int {
    candidate, count := 0, 0
    
    for _, num := range nums {
        if count == 0 {
            candidate = num
        }
        if num == candidate {
            count++
        } else {
            count--
        }
    }
    return candidate
}
```

**解题思路**：
- 哈希表：统计每个元素出现次数，超过一半即为答案
- 投票算法：不同元素相互抵消，最后剩下的就是多数元素

### 4. 排序法

**适用场景**：
- 寻找第 K 大/小元素
- 合并有序数组
- 数组中出现频率最高的元素

**核心思想**：
- 排序后某些问题会变得简单
- 注意题目是否允许修改原数组

#### 示例：合并两个有序数组（LeetCode 88）

```go
func merge(nums1 []int, m int, nums2 []int, n int) {
    // 从后往前合并，避免覆盖 nums1 的有效元素
    p1, p2 := m-1, n-1
    tail := m + n - 1
    
    for p1 >= 0 || p2 >= 0 {
        var val int
        if p1 == -1 {
            val = nums2[p2]
            p2--
        } else if p2 == -1 {
            val = nums1[p1]
            p1--
        } else if nums1[p1] > nums2[p2] {
            val = nums1[p1]
            p1--
        } else {
            val = nums2[p2]
            p2--
        }
        nums1[tail] = val
        tail--
    }
}
```

**解题思路**：
1. 从后往前合并，利用 nums1 尾部的空闲空间
2. 比较两个数组的末尾元素，将较大的放到尾部
3. 避免从前向后合并导致的元素覆盖问题

### 5. 前缀和

**适用场景**：
- 频繁计算区间和
- 寻找和为 K 的子数组
- 二维矩阵区域和

**核心思想**：
- 预处理：`prefix[i] = nums[0] + nums[1] + ... + nums[i-1]`
- 区间和：`sum(i, j) = prefix[j+1] - prefix[i]`

#### 示例：和为 K 的子数组个数

```go
func subarraySum(nums []int, k int) int {
    // key: 前缀和, value: 出现次数
    prefixCount := map[int]int{0: 1}
    prefixSum := 0
    count := 0
    
    for _, num := range nums {
        prefixSum += num
        
        // 如果存在 prefixSum - k，说明有子数组和为 k
        if cnt, ok := prefixCount[prefixSum-k]; ok {
            count += cnt
        }
        
        prefixCount[prefixSum]++
    }
    
    return count
}
```

**解题思路**：
1. 维护当前前缀和 `prefixSum`
2. 如果之前出现过 `prefixSum - k`，说明从那个位置到当前位置的子数组和为 k
3. 用哈希表记录每个前缀和出现的次数

### 6. 二分查找

**适用场景**：
- 有序数组查找
- 寻找边界（第一个/最后一个满足条件的位置）
- 搜索旋转排序数组

**核心思想**：
- 每次排除一半的搜索空间
- 时间复杂度 O(log n)

#### 示例：在排序数组中查找元素的第一个和最后一个位置

```go
func searchRange(nums []int, target int) []int {
    left := findLeftBound(nums, target)
    right := findRightBound(nums, target)
    return []int{left, right}
}

func findLeftBound(nums []int, target int) int {
    left, right := 0, len(nums)-1
    for left <= right {
        mid := left + (right-left)/2
        if nums[mid] < target {
            left = mid + 1
        } else {
            right = mid - 1
        }
    }
    if left >= len(nums) || nums[left] != target {
        return -1
    }
    return left
}

func findRightBound(nums []int, target int) int {
    left, right := 0, len(nums)-1
    for left <= right {
        mid := left + (right-left)/2
        if nums[mid] <= target {
            left = mid + 1
        } else {
            right = mid - 1
        }
    }
    if right < 0 || nums[right] != target {
        return -1
    }
    return right
}
```

## 三、解题通用步骤

### Step 1: 分析题目特征
- 数组是否有序？
- 是否需要保持相对顺序？
- 是否涉及连续子数组？
- 是否需要统计频次？

### Step 2: 选择合适的方法
| 特征 | 推荐方法 |
|------|----------|
| 有序数组 + 去重/查找 | 双指针、二分查找 |
| 连续子数组 | 滑动窗口、前缀和 |
| 查找/计数 | 哈希表 |
| 第K大/合并 | 排序、堆 |
| 最值优化 | 动态规划、贪心 |

### Step 3: 画图辅助理解
- 画出数组和指针的移动过程
- 标注关键变量（窗口边界、前缀和等）
- 模拟几个测试用例

### Step 4: 处理边界情况
- 空数组
- 只有一个元素
- 全部元素相同
- 没有满足条件的解

## 五、常见陷阱与注意事项

1. **数组越界**：访问 `nums[i]` 前检查 `i` 的范围
2. **空指针**：处理空数组或长度为 0 的情况
3. **整数溢出**：累加时使用更大的类型（如 Go 的 `int64`）
4. **原地修改**：注意题目是否要求原地操作，不要额外开辟空间
5. **稳定性**：某些算法可能改变相同元素的相对顺序

## 七、总结

掌握数组算法的关键：
1. **理解每种方法的适用场景**：看到题目能快速联想到合适的解法
2. **熟练运用模板**：双指针、滑动窗口都有固定套路
3. **多画图模拟**：帮助理解指针移动和状态变化
4. **注重边界条件**：大部分 bug 都来自边界处理不当
5. **刻意练习**：按照题单循序渐进，从易到难

> 💡 **学习建议**：先理解思路 → 手写代码 → 调试测试 → 总结模板 → 举一反三
