## 📊 数据结构对比速查表

| 数据结构 | 查找 | 插入 | 删除 | 适用场景 |
|---------|------|------|------|---------|
| 数组 | O(1)* | O(n) | O(n) | 随机访问、连续存储 |
| 链表 | O(n) | O(1)* | O(1)* | 频繁插入删除 |
| 栈 | O(n) | O(1) | O(1) | 括号匹配、DFS |
| 队列 | O(n) | O(1) | O(1) | BFS、层序遍历 |
| 哈希表 | O(1) | O(1) | O(1) | 快速查找、计数 |
| 二叉搜索树 | O(log n) | O(log n) | O(log n) | 有序数据、范围查询 |
| 堆 | O(1)** | O(log n) | O(log n) | Top K、优先队列 |
| 图 | O(V+E) | O(1) | O(1) | 网络、关系建模 |

*已知位置时  
**只能获取堆顶元素

## 💡 解题通用框架

### Step 1: 理解问题
- 输入是什么？输出是什么？
- 有什么约束条件？
- 举几个例子验证理解

### Step 2: 选择数据结构
根据问题特征选择：
- 需要快速查找 → 哈希表
- 需要维护顺序 → 堆/平衡树
- 涉及层次关系 → 树/图
- 需要后进先出 → 栈
- 需要先进先出 → 队列

### Step 3: 选择算法
- 查找问题 → 二分查找、哈希
- 最优化问题 → 动态规划、贪心
- 排列组合 → 回溯
- 连通性 → DFS/BFS/并查集
- 最短路径 → BFS/Dijkstra

### Step 4: 实现代码
- 先写伪代码
- 处理边界情况
- 注意变量命名

### Step 5: 测试验证
- 正常用例
- 边界用例（空、单元素、极大值）
- 特殊用例（重复、负数、溢出）

## 🎓 学习建议

### 1. 循序渐进
不要急于求成，按照学习路线逐步推进，每个阶段都要扎实掌握。

### 2. 理解优先
先理解算法思想和原理，再背诵模板，最后刷题巩固。

### 3. 画图辅助
对于链表、树、图等问题，一定要画图模拟过程。

### 4. 总结归纳
每做完一类题目，总结解题模式和套路。

### 5. 刻意练习
针对薄弱环节专项训练，不要只做自己擅长的题型。

### 6. 复习巩固
定期回顾之前学过的内容，避免遗忘。
