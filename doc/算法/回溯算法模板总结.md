## 回溯算法模板总结

### 一、核心框架

所有回溯问题都遵循这个通用框架：

```go
func backtrack(参数...) {
    if 满足结束条件 {
        收集结果
        return
    }
    
    for 选择 in 选择列表 {
        做选择
        backtrack(新参数...)
        撤销选择
    }
}
```

关键区别在于：**选择列表如何定义** 和 **结束条件如何判断**。

## 二、三大核心模板

### 1. 子集/组合模板（同一组元素，顺序无关）

**特征**：
- 从同一组元素中选择
- 顺序不重要 `[1,2] = [2,1]`
- 每个元素只能选一次
- 长度可变

**模板代码**：
```go
func subsets(nums []int) [][]int {
    result := [][]int{}
    backtrack(nums, 0, []int{}, &result)
    return result
}

func backtrack(nums []int, start int, current []int, result *[][]int) {
    // 收集所有节点（包括空集和中间节点）
    temp := make([]int, len(current))
    copy(temp, current)
    *result = append(*result, temp)
    
    // 选择列表：从 start 开始，避免回头
    for i := start; i < len(nums); i++ {
        current = append(current, nums[i])
        backtrack(nums, i+1, current, result)  // i+1：不重复使用
        current = current[:len(current)-1]
    }
}
```

**变种1：组合总和（可重复使用）**
```go
func combinationSum(candidates []int, target int) [][]int {
    result := [][]int{}
    sort.Ints(candidates)  // 便于剪枝
    backtrack(candidates, 0, 0, target, []int{}, &result)
    return result
}

func backtrack(candidates []int, start, sum, target int, current []int, result *[][]int) {
    if sum == target {
        temp := make([]int, len(current))
        copy(temp, current)
        *result = append(*result, temp)
        return
    }
    if sum > target {
        return
    }
    
    for i := start; i < len(candidates); i++ {
        if sum+candidates[i] > target {
            break  // 剪枝
        }
        current = append(current, candidates[i])
        backtrack(candidates, i, sum+candidates[i], target, current, result)  // i：可重复使用
        current = current[:len(current)-1]
    }
}
```

**变种2：子集/组合有重复元素**
```go
func subsetsWithDup(nums []int) [][]int {
    result := [][]int{}
    sort.Ints(nums)  // 排序以便去重
    backtrack(nums, 0, []int{}, &result)
    return result
}

func backtrack(nums []int, start int, current []int, result *[][]int) {
    temp := make([]int, len(current))
    copy(temp, current)
    *result = append(*result, temp)
    
    for i := start; i < len(nums); i++ {
        // 跳过重复元素
        if i > start && nums[i] == nums[i-1] {
            continue
        }
        current = append(current, nums[i])
        backtrack(nums, i+1, current, result)
        current = current[:len(current)-1]
    }
}
```

### 2. 全排列模板（同一组元素，顺序相关）

**特征**：
- 从同一组元素中选择
- 顺序重要 `[1,2] ≠ [2,1]`
- 每个元素只能选一次
- 长度固定 = n

**模板代码**：
```go
func permute(nums []int) [][]int {
    result := [][]int{}
    used := make([]bool, len(nums))
    backtrack(nums, used, []int{}, &result)
    return result
}

func backtrack(nums []int, used []bool, current []int, result *[][]int) {
    // 只收集叶子节点（长度等于 n）
    if len(current) == len(nums) {
        temp := make([]int, len(current))
        copy(temp, current)
        *result = append(*result, temp)
        return
    }
    
    // 选择列表：每次都从头开始
    for i := 0; i < len(nums); i++ {
        if used[i] {
            continue
        }
        current = append(current, nums[i])
        used[i] = true
        backtrack(nums, used, current, result)
        current = current[:len(current)-1]
        used[i] = false
    }
}
```

**变种：有重复元素的全排列**
```go
func permuteUnique(nums []int) [][]int {
    result := [][]int{}
    used := make([]bool, len(nums))
    sort.Ints(nums)  // 排序以便去重
    backtrack(nums, used, []int{}, &result)
    return result
}

func backtrack(nums []int, used []bool, current []int, result *[][]int) {
    if len(current) == len(nums) {
        temp := make([]int, len(current))
        copy(temp, current)
        *result = append(*result, temp)
        return
    }
    
    for i := 0; i < len(nums); i++ {
        if used[i] {
            continue
        }
        // 跳过重复：前一个相同元素未被使用，说明在同一层被跳过
        if i > 0 && nums[i] == nums[i-1] && !used[i-1] {
            continue
        }
        current = append(current, nums[i])
        used[i] = true
        backtrack(nums, used, current, result)
        current = current[:len(current)-1]
        used[i] = false
    }
}
```

### 3. 笛卡尔积模板（多组独立选择）

**特征**：
- 每组独立选择（不同位置有不同选项）
- 顺序固定（按组顺序）
- 每组必须选一个
- 长度固定 = 组数

**模板代码**：
```go
func cartesian(groups [][]int) [][]int {
    result := [][]int{}
    backtrack(groups, 0, []int{}, &result)
    return result
}

func backtrack(groups [][]int, index int, current []int, result *[][]int) {
    // 只收集叶子节点（处理完所有组）
    if index == len(groups) {
        temp := make([]int, len(current))
        copy(temp, current)
        *result = append(*result, temp)
        return
    }
    
    // 选择列表：只遍历当前组
    for i := 0; i < len(groups[index]); i++ {
        current = append(current, groups[index][i])
        backtrack(groups, index+1, current, result)  // index+1：进入下一组
        current = current[:len(current)-1]
    }
}
```

**经典应用：电话号码字母组合**
```go
func letterCombinations(digits string) []string {
    if len(digits) == 0 {
        return []string{}
    }
    
    phone := map[byte]string{
        '2': "abc", '3': "def", '4': "ghi", '5': "jkl",
        '6': "mno", '7': "pqrs", '8': "tuv", '9': "wxyz",
    }
    
    groups := make([]string, len(digits))
    for i := 0; i < len(digits); i++ {
        groups[i] = phone[digits[i]]
    }
    
    result := []string{}
    backtrack(groups, 0, []byte{}, &result)
    return result
}

func backtrack(groups []string, index int, current []byte, result *[]string) {
    if index == len(groups) {
        *result = append(*result, string(current))
        return
    }
    
    for i := 0; i < len(groups[index]); i++ {
        current = append(current, groups[index][i])
        backtrack(groups, index+1, current, result)
        current = current[:len(current)-1]
    }
}
```

## 三、模板对比表

| 特性           | 子集/组合              | 全排列              | 笛卡尔积               |
| -------------- | ---------------------- | ------------------- | ---------------------- |
| **选择范围**   | 同一组元素             | 同一组元素          | 多组独立               |
| **递归参数**   | `start`                | `used` 数组         | `index`                |
| **循环起点**   | `i := start`           | `i := 0`            | `i := 0`（但组固定）   |
| **结束条件**   | 无固定（收集所有节点） | `len(current) == n` | `index == len(groups)` |
| **收集时机**   | 所有节点               | 叶子节点            | 叶子节点               |
| **去重方式**   | `start` + 排序跳过     | `used` + 排序跳过   | 无需去重               |
| **时间复杂度** | O(2^n)                 | O(n!)               | O(k^n)                 |

## 四、快速判断流程

```
开始
  ↓
是否多组独立选择？
  ↓ 是
【笛卡尔积模板】
  ↓ 否（同一组元素）
  ↓
顺序是否重要？
  ↓ 是          ↓ 否
【全排列模板】  【子集模板】
  ↓              ↓
是否可重复？    是否可重复？
  ↓              ↓
used数组       start参数
```

## 五、记忆口诀

```
子集组合用 start，不回头来不重复
全排列用 used 数组，回头但不重复
笛卡尔积用 index，各组独立不干扰

重复元素先排序，跳过条件要记牢
子集去重看 start，排列去重看 used
可重复用传 i 不传 i+1
```

## 六、常见问题归类

| 问题       | 类型         | 关键点                       |
| ---------- | ------------ | ---------------------------- |
| 子集       | 子集         | 收集所有节点                 |
| 组合总和   | 子集变种     | 传 `i` 可重复，可剪枝        |
| 子集 II    | 子集变种     | 排序 + `i > start` 去重      |
| 全排列     | 全排列       | used 数组，收集叶子节点      |
| 全排列 II  | 全排列变种   | 排序 + `!used[i-1]` 去重     |
| 电话号码   | 笛卡尔积     | 多组独立，`index` 参数       |
| N皇后      | 全排列变种   | 每行选一列，用列和对角线标记 |
| 分割回文串 | 子集变种     | 在间隙切，需判断回文         |
| 括号生成   | 笛卡尔积变种 | 两个组：左括号数、右括号数   |
