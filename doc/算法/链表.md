# 链表

## 一、链表基础概念

链表是一种线性数据结构，特点：
- **非连续内存存储**：节点通过指针连接
- **动态大小**：可以灵活增删节点
- **插入/删除高效**：O(1) 时间复杂度（已知位置）
- **随机访问低效**：需要从头遍历，O(n) 时间复杂度

### 链表类型
- **单链表**：每个节点只有一个 next 指针
- **双链表**：每个节点有 prev 和 next 两个指针
- **循环链表**：尾节点指向头节点

### Go 语言链表节点定义
```go
// 单链表节点
type ListNode struct {
    Val  int
    Next *ListNode
}

// 双链表节点
type DoublyListNode struct {
    Val  int
    Prev *DoublyListNode
    Next *DoublyListNode
}
```

## 二、常见题型分类

### 1. 双指针法（快慢指针）

**适用场景**：
- 判断链表是否有环
- 寻找链表中点
- 寻找倒数第 K 个节点
- 删除倒数第 N 个节点

**核心思想**：
- 快指针每次走 2 步，慢指针每次走 1 步
- 当快指针到达末尾时，慢指针在中点

#### 示例1：判断链表是否有环（LeetCode 141）

```go
func hasCycle(head *ListNode) bool {
    if head == nil || head.Next == nil {
        return false
    }
    
    slow, fast := head, head.Next
    for fast != nil && fast.Next != nil {
        if slow == fast {
            return true // 相遇说明有环
        }
        slow = slow.Next       // 走1步
        fast = fast.Next.Next  // 走2步
    }
    return false
}
```

**解题思路**：
1. 快慢指针从不同位置出发
2. 如果有环，快指针最终会追上慢指针
3. 如果无环，快指针会先到达末尾

#### 示例2：寻找链表中点（LeetCode 876）

```go
func middleNode(head *ListNode) *ListNode {
    slow, fast := head, head
    for fast != nil && fast.Next != nil {
        slow = slow.Next       // 走1步
        fast = fast.Next.Next  // 走2步
    }
    return slow // 慢指针正好在中点
}
```

**解题思路**：
- 快指针走到末尾时，慢指针走了 half 距离
- 偶数个节点时，返回第二个中点

#### 示例3：删除倒数第 N 个节点（LeetCode 19）

```go
func removeNthFromEnd(head *ListNode, n int) *ListNode {
    dummy := &ListNode{Next: head}
    first, second := dummy, dummy
    
    // first 先走 n+1 步
    for i := 0; i <= n; i++ {
        first = first.Next
    }
    
    // 两个指针同时移动，直到 first 到达末尾
    for first != nil {
        first = first.Next
        second = second.Next
    }
    
    // second 的下一个就是要删除的节点
    second.Next = second.Next.Next
    return dummy.Next
}
```

**解题思路**：
1. 使用虚拟头节点简化边界处理
2. 让两个指针保持 n 的距离
3. 当第一个指针到末尾时，第二个指针在倒数第 n+1 个位置

### 2. 反转链表

**适用场景**：
- 反转整个链表
- 反转部分链表
- K 个一组翻转链表

**核心思想**：
- 迭代法：逐个改变节点的 next 指针方向
- 递归法：从后往前反转

#### 示例1：反转链表（LeetCode 206）

```go
// 迭代法
func reverseList(head *ListNode) *ListNode {
    var prev *ListNode
    curr := head
    
    for curr != nil {
        next := curr.Next   // 保存下一个节点
        curr.Next = prev    // 反转指针
        prev = curr         // prev 前进一步
        curr = next         // curr 前进一步
    }
    return prev
}

// 递归法
func reverseListRecursive(head *ListNode) *ListNode {
    if head == nil || head.Next == nil {
        return head
    }
    
    newHead := reverseListRecursive(head.Next)
    head.Next.Next = head  // 反转当前节点
    head.Next = nil        // 断开原指针
    return newHead
}
```

**解题思路（迭代法）**：
1. 维护三个指针：prev、curr、next
2. 逐个反转指针方向
3. 最后 prev 指向新的头节点

#### 示例2：反转链表 II（LeetCode 92）

```go
func reverseBetween(head *ListNode, left int, right int) *ListNode {
    dummy := &ListNode{Next: head}
    prev := dummy
    
    // 找到 left 的前一个节点
    for i := 0; i < left-1; i++ {
        prev = prev.Next
    }
    
    // 反转 [left, right] 区间
    curr := prev.Next
    for i := 0; i < right-left; i++ {
        next := curr.Next
        curr.Next = next.Next
        next.Next = prev.Next
        prev.Next = next
    }
    
    return dummy.Next
}
```

### 3. 合并链表

**适用场景**：
- 合并两个有序链表
- 合并 K 个有序链表

#### 示例：合并两个有序链表（LeetCode 21）

```go
func mergeTwoLists(l1 *ListNode, l2 *ListNode) *ListNode {
    dummy := &ListNode{}
    curr := dummy
    
    for l1 != nil && l2 != nil {
        if l1.Val <= l2.Val {
            curr.Next = l1
            l1 = l1.Next
        } else {
            curr.Next = l2
            l2 = l2.Next
        }
        curr = curr.Next
    }
    
    // 连接剩余部分
    if l1 != nil {
        curr.Next = l1
    }
    if l2 != nil {
        curr.Next = l2
    }
    
    return dummy.Next
}
```

**解题思路**：
1. 使用虚拟头节点简化操作
2. 比较两个链表的当前节点，选择较小的
3. 最后连接剩余部分

### 4. 链表排序

**适用场景**：
- 对链表进行排序
- 利用归并排序的特性

#### 示例：排序链表（LeetCode 148）

```go
func sortList(head *ListNode) *ListNode {
    if head == nil || head.Next == nil {
        return head
    }
    
    // 找到中点并断开
    mid := getMid(head)
    left := sortList(head)
    right := sortList(mid)
    
    return mergeTwoLists(left, right)
}

func getMid(head *ListNode) *ListNode {
    var prev *ListNode
    slow, fast := head, head
    
    for fast != nil && fast.Next != nil {
        prev = slow
        slow = slow.Next
        fast = fast.Next.Next
    }
    
    if prev != nil {
        prev.Next = nil // 断开链表
    }
    return slow
}
```

**解题思路**：
1. 使用归并排序（适合链表）
2. 快慢指针找中点并断开
3. 递归排序左右两部分
4. 合并两个有序链表

## 三、解题通用步骤

### Step 1: 画图辅助
- 画出链表结构和指针位置
- 标注关键节点（头节点、尾节点、目标节点）
- 模拟指针移动过程

### Step 2: 处理特殊情况
- 空链表
- 只有一个节点
- 操作头节点（使用虚拟头节点）
- 环的存在

### Step 3: 选择合适的方法
| 问题类型 | 推荐方法 |
|---------|---------|
| 找中点/环/倒数第K个 | 快慢指针 |
| 反转/重排 | 迭代或递归 |
| 合并/排序 | 归并思想 |
| 分组操作 | dummy 节点 + 指针追踪 |

### Step 4: 验证指针操作
- 确保没有丢失节点引用
- 检查是否形成意外环
- 验证边界条件

## 五、常见陷阱与注意事项

1. **空指针异常**：访问 `node.Next` 前检查 `node != nil`
2. **丢失节点引用**：反转或断开前先保存 next
3. **环的处理**：检测环后再进行其他操作
4. **虚拟头节点**：涉及头节点操作时使用 dummy 简化代码
5. **内存泄漏**：Go 有 GC，但要注意断开不必要的引用

## 七、总结

掌握链表的关键：
1. **理解指针操作**：画图是理解的关键

3. **掌握快慢指针**：解决很多链表问题
4. **注意边界条件**：空链表、单节点、环
5. **多练习指针追踪**：培养空间想象力
