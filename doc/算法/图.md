# 图

## 一、基础概念

图（Graph）是一种非线性数据结构，由节点（顶点）和边组成，特点：
- **节点（Vertex）**：图中的元素
- **边（Edge）**：节点之间的连接关系
- **有向图 vs 无向图**：边是否有方向
- **加权图 vs 无权图**：边是否有权重
- **连通图**：任意两个节点之间都有路径

### 图的表示方法

#### 1. 邻接表（推荐）

```go
// 无权图
type Graph struct {
    adj map[int][]int // adj[u] 存储 u 的所有邻居
}

func NewGraph() *Graph {
    return &Graph{
        adj: make(map[int][]int),
    }
}

func (g *Graph) AddEdge(u, v int) {
    g.adj[u] = append(g.adj[u], v)
    g.adj[v] = append(g.adj[v], u) // 无向图需要双向添加
}

// 有权图
type WeightedGraph struct {
    adj map[int][]Edge
}

type Edge struct {
    to     int
    weight int
}

func (g *WeightedGraph) AddEdge(u, v, w int) {
    g.adj[u] = append(g.adj[u], Edge{to: v, weight: w})
    g.adj[v] = append(g.adj[v], Edge{to: u, weight: w})
}
```

#### 2. 邻接矩阵

```go
// 适用于稠密图
adjMatrix := make([][]bool, n)
for i := range adjMatrix {
    adjMatrix[i] = make([]bool, n)
}
adjMatrix[u][v] = true // u 和 v 之间有边
```

**选择建议**：
- 稀疏图（边少）→ 邻接表，空间 O(V+E)
- 稠密图（边多）→ 邻接矩阵，空间 O(V²)

## 二、图的遍历

### 1. 深度优先搜索（DFS）

**适用场景**：
- 判断连通性
- 寻找路径
- 拓扑排序
- 检测环

#### DFS 模板

```go
func dfs(graph map[int][]int, node int, visited map[int]bool) {
    if visited[node] {
        return
    }
    
    visited[node] = true
    // 处理当前节点
    
    for _, neighbor := range graph[node] {
        dfs(graph, neighbor, visited)
    }
}

// 使用示例
visited := make(map[int]bool)
for node := range graph {
    if !visited[node] {
        dfs(graph, node, visited)
    }
}
```

#### 示例：岛屿数量（LeetCode 200）

```go
func numIslands(grid [][]byte) int {
    if len(grid) == 0 || len(grid[0]) == 0 {
        return 0
    }
    
    rows, cols := len(grid), len(grid[0])
    count := 0
    
    for r := 0; r < rows; r++ {
        for c := 0; c < cols; c++ {
            if grid[r][c] == '1' {
                count++
                dfs(grid, r, c)
            }
        }
    }
    
    return count
}

func dfs(grid [][]byte, r, c int) {
    rows, cols := len(grid), len(grid[0])
    
    // 边界检查和终止条件
    if r < 0 || r >= rows || c < 0 || c >= cols || grid[r][c] == '0' {
        return
    }
    
    grid[r][c] = '0' // 标记为已访问
    
    // 四个方向
    dfs(grid, r+1, c)
    dfs(grid, r-1, c)
    dfs(grid, r, c+1)
    dfs(grid, r, c-1)
}
```

### 2. 广度优先搜索（BFS）

**适用场景**：
- 最短路径（无权图）
- 层序遍历
- 最小操作次数

#### BFS 模板

```go
func bfs(graph map[int][]int, start int) {
    visited := make(map[int]bool)
    queue := []int{start}
    visited[start] = true
    
    for len(queue) > 0 {
        node := queue[0]
        queue = queue[1:]
        
        // 处理当前节点
        
        for _, neighbor := range graph[node] {
            if !visited[neighbor] {
                visited[neighbor] = true
                queue = append(queue, neighbor)
            }
        }
    }
}
```

#### 示例：完全平方数（LeetCode 279）

```go
func numSquares(n int) int {
    // BFS 求最短路径
    queue := []int{n}
    visited := make(map[int]bool)
    visited[n] = true
    
    level := 0
    
    for len(queue) > 0 {
        level++
        size := len(queue)
        
        for i := 0; i < size; i++ {
            curr := queue[0]
            queue = queue[1:]
            
            // 尝试减去所有可能的完全平方数
            for j := 1; j*j <= curr; j++ {
                next := curr - j*j
                if next == 0 {
                    return level
                }
                if !visited[next] {
                    visited[next] = true
                    queue = append(queue, next)
                }
            }
        }
    }
    
    return level
}
```

## 三、常见题型分类

### 1. 拓扑排序

**适用场景**：
- 课程安排（依赖关系）
- 任务调度
- 编译顺序
- 检测有向图中的环

**核心思想**：
- Kahn 算法：基于入度的 BFS
- DFS 方法：后序遍历的逆序

#### 示例：课程表（LeetCode 207）

```go
func canFinish(numCourses int, prerequisites [][]int) bool {
    // 构建图和入度数组
    graph := make(map[int][]int)
    inDegree := make([]int, numCourses)
    
    for _, pre := range prerequisites {
        course, prereq := pre[0], pre[1]
        graph[prereq] = append(graph[prereq], course)
        inDegree[course]++
    }
    
    // 将所有入度为 0 的节点加入队列
    queue := []int{}
    for i := 0; i < numCourses; i++ {
        if inDegree[i] == 0 {
            queue = append(queue, i)
        }
    }
    
    completed := 0
    
    for len(queue) > 0 {
        course := queue[0]
        queue = queue[1:]
        completed++
        
        // 减少邻居的入度
        for _, next := range graph[course] {
            inDegree[next]--
            if inDegree[next] == 0 {
                queue = append(queue, next)
            }
        }
    }
    
    return completed == numCourses
}
```

**解题思路**：
1. 计算每个节点的入度
2. 将入度为 0 的节点加入队列
3. 依次处理队列中的节点，减少邻居的入度
4. 如果最终处理的节点数等于总节点数，说明无环

### 2. 最短路径

**适用场景**：
- 无权图最短路径 → BFS
- 有权图最短路径（非负权）→ Dijkstra
- 有负权边 → Bellman-Ford
- 所有点对最短路径 → Floyd-Warshall

#### 示例：网络延迟时间（LeetCode 743）- Dijkstra 算法

```go
func networkDelayTime(times [][]int, n int, k int) int {
    // 构建邻接表
    graph := make(map[int][]Edge)
    for _, time := range times {
        u, v, w := time[0], time[1], time[2]
        graph[u] = append(graph[u], Edge{to: v, weight: w})
    }
    
    // Dijkstra 算法
    dist := make([]int, n+1)
    for i := range dist {
        dist[i] = math.MaxInt32
    }
    dist[k] = 0
    
    // 使用最小堆
    h := &MinHeap{}
    heap.Init(h)
    heap.Push(h, Edge{to: k, weight: 0})
    
    for h.Len() > 0 {
        curr := heap.Pop(h).(Edge)
        u, d := curr.to, curr.weight
        
        if d > dist[u] {
            continue
        }
        
        for _, edge := range graph[u] {
            v, w := edge.to, edge.weight
            if dist[u]+w < dist[v] {
                dist[v] = dist[u] + w
                heap.Push(h, Edge{to: v, weight: dist[v]})
            }
        }
    }
    
    // 找到最大距离
    maxDist := 0
    for i := 1; i <= n; i++ {
        if dist[i] == math.MaxInt32 {
            return -1 // 有节点不可达
        }
        if dist[i] > maxDist {
            maxDist = dist[i]
        }
    }
    
    return maxDist
}

type Edge struct {
    to, weight int
}

type MinHeap []Edge

func (h MinHeap) Len() int           { return len(h) }
func (h MinHeap) Less(i, j int) bool { return h[i].weight < h[j].weight }
func (h MinHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }
func (h *MinHeap) Push(x interface{}) { *h = append(*h, x.(Edge)) }
func (h *MinHeap) Pop() interface{} {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[:n-1]
    return x
}
```

### 3. 并查集（Union-Find）

**适用场景**：
- 连通分量计数
- 判断两个节点是否连通
- Kruskal 最小生成树算法
- 检测无向图中的环

**核心思想**：
- find：查找根节点（带路径压缩）
- union：合并两个集合（按秩合并）

#### 并查集模板

```go
type UnionFind struct {
    parent []int
    rank   []int
    count  int // 连通分量数量
}

func NewUnionFind(n int) *UnionFind {
    parent := make([]int, n)
    rank := make([]int, n)
    for i := 0; i < n; i++ {
        parent[i] = i
        rank[i] = 1
    }
    return &UnionFind{
        parent: parent,
        rank:   rank,
        count:  n,
    }
}

func (uf *UnionFind) Find(x int) int {
    if uf.parent[x] != x {
        uf.parent[x] = uf.Find(uf.parent[x]) // 路径压缩
    }
    return uf.parent[x]
}

func (uf *UnionFind) Union(x, y int) bool {
    rootX := uf.Find(x)
    rootY := uf.Find(y)
    
    if rootX == rootY {
        return false // 已经在同一集合
    }
    
    // 按秩合并
    if uf.rank[rootX] < uf.rank[rootY] {
        uf.parent[rootX] = rootY
    } else if uf.rank[rootX] > uf.rank[rootY] {
        uf.parent[rootY] = rootX
    } else {
        uf.parent[rootY] = rootX
        uf.rank[rootX]++
    }
    
    uf.count--
    return true
}

func (uf *UnionFind) Connected(x, y int) bool {
    return uf.Find(x) == uf.Find(y)
}
```

#### 示例：冗余连接（LeetCode 684）

```go
func findRedundantConnection(edges [][]int) []int {
    n := len(edges)
    uf := NewUnionFind(n + 1)
    
    for _, edge := range edges {
        u, v := edge[0], edge[1]
        if !uf.Union(u, v) {
            // 如果已经在同一集合，这条边会形成环
            return edge
        }
    }
    
    return []int{}
}
```

### 4. 最小生成树（MST）

**适用场景**：
- 连接所有节点的最小成本
- 网络设计
- 电路布线

**算法**：
- Kruskal 算法：基于并查集，适合稀疏图
- Prim 算法：基于优先队列，适合稠密图

#### 示例：Kruskal 算法

```go
func minimumCost(n int, connections [][]int) int {
    // 按权重排序
    sort.Slice(connections, func(i, j int) bool {
        return connections[i][2] < connections[j][2]
    })
    
    uf := NewUnionFind(n + 1)
    totalCost := 0
    edgesUsed := 0
    
    for _, conn := range connections {
        u, v, w := conn[0], conn[1], conn[2]
        if uf.Union(u, v) {
            totalCost += w
            edgesUsed++
            if edgesUsed == n-1 {
                break // MST 完成
            }
        }
    }
    
    if edgesUsed != n-1 {
        return -1 // 无法连接所有节点
    }
    
    return totalCost
}
```

## 四、解题通用步骤

### Step 1: 识别图的问题
- 涉及节点之间的关系 → 图
- 依赖关系、先后顺序 → 拓扑排序
- 最短/最小路径 → BFS/Dijkstra
- 连通性问题 → DFS/BFS/并查集
- 最小成本连接 → 最小生成树

### Step 2: 选择图的表示
| 图的特点 | 推荐表示 |
|---------|---------|
| 稀疏图 | 邻接表 |
| 稠密图 | 邻接矩阵 |
| 有权图 | 邻接表 + 权重 |
| 网格图 | 二维数组 + 方向数组 |

### Step 3: 选择遍历算法
| 问题类型 | 推荐算法 |
|---------|---------|
| 连通性、路径存在性 | DFS |
| 最短路径（无权） | BFS |
| 最短路径（有权） | Dijkstra |
| 拓扑排序 | Kahn 算法或 DFS |
| 连通分量 | 并查集或 DFS |

### Step 4: 处理特殊情况
- 孤立节点
- 不连通图
- 有环图
- 空图

## 六、常见陷阱与注意事项

1. ** visited 标记**：DFS/BFS 一定要标记已访问节点，避免死循环
2. **图的连通性**：可能需要从多个起点开始遍历
3. **边界条件**：空图、单节点图、不连通图
4. **有向图 vs 无向图**：添加边时注意是否需要双向
5. **权重为负**：Dijkstra 不支持负权边，需要用 Bellman-Ford

// 3. 图的深拷贝
func cloneGraph(node *Node) *Node {
    if node == nil {
        return nil
    }
    
    clones := make(map[int]*Node)
    var dfs func(n *Node) *Node
    dfs = func(n *Node) *Node {
        if clone, ok := clones[n.Val]; ok {
            return clone
        }
        
        clone := &Node{Val: n.Val}
        clones[n.Val] = clone
        
        for _, neighbor := range n.Neighbors {
            clone.Neighbors = append(clone.Neighbors, dfs(neighbor))
        }
        
        return clone
    }
    
    return dfs(node)
}

// 4. 打印图（调试用）
func printGraph(graph map[int][]int) {
    for node, neighbors := range graph {
        fmt.Printf("%d -> %v\n", node, neighbors)
    }
}

## 九、图算法速查表

| 算法 | 时间复杂度 | 适用场景 |
|------|-----------|---------|
| DFS | O(V+E) | 连通性、路径、环检测 |
| BFS | O(V+E) | 最短路径（无权）、层序遍历 |
| Dijkstra | O((V+E)log V) | 最短路径（非负权） |
| Bellman-Ford | O(VE) | 最短路径（支持负权） |
| Floyd-Warshall | O(V³) | 所有点对最短路径 |
| Kahn 算法 | O(V+E) | 拓扑排序 |
| Kruskal | O(E log E) | 最小生成树 |
| Prim | O((V+E)log V) | 最小生成树 |
| 并查集 | O(α(n)) ≈ O(1) | 连通性、动态集合 |

*V = 节点数，E = 边数，α = 反阿克曼函数*
