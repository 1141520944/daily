# 栈和队列

## 一、基础概念

### 栈（Stack）
**特点**：后进先出（LIFO - Last In First Out）
- 只能在一端（栈顶）进行插入和删除
- 主要操作：push（入栈）、pop（出栈）、peek（查看栈顶）
- 时间复杂度：O(1)

### 队列（Queue）
**特点**：先进先出（FIFO - First In First Out）
- 在一端（队尾）插入，在另一端（队头）删除
- 主要操作：enqueue（入队）、dequeue（出队）、front（查看队头）
- 时间复杂度：O(1)

### Go 语言实现

```go
// 使用切片实现栈
type Stack []int

func (s *Stack) Push(v int) {
    *s = append(*s, v)
}

func (s *Stack) Pop() int {
    n := len(*s)
    if n == 0 {
        panic("stack is empty")
    }
    val := (*s)[n-1]
    *s = (*s)[:n-1]
    return val
}

func (s *Stack) Peek() int {
    n := len(*s)
    if n == 0 {
        panic("stack is empty")
    }
    return (*s)[n-1]
}

func (s *Stack) IsEmpty() bool {
    return len(*s) == 0
}

// 使用切片实现队列
type Queue []int

func (q *Queue) Enqueue(v int) {
    *q = append(*q, v)
}

func (q *Queue) Dequeue() int {
    if len(*q) == 0 {
        panic("queue is empty")
    }
    val := (*q)[0]
    *q = (*q)[1:]
    return val
}

func (q *Queue) Front() int {
    if len(*q) == 0 {
        panic("queue is empty")
    }
    return (*q)[0]
}
```

## 二、栈的常见题型

### 1. 括号匹配

**适用场景**：
- 验证括号有效性
- 最长有效括号
- 最小添加使括号有效

**核心思想**：
- 左括号入栈，右括号与栈顶匹配
- 匹配成功则弹出，否则无效

#### 示例：有效的括号（LeetCode 20）

```go
func isValid(s string) bool {
    stack := []rune{}
    mapping := map[rune]rune{
        ')': '(',
        '}': '{',
        ']': '[',
    }
    
    for _, ch := range s {
        if ch == '(' || ch == '{' || ch == '[' {
            stack = append(stack, ch) // 左括号入栈
        } else {
            // 右括号：检查是否匹配
            if len(stack) == 0 || stack[len(stack)-1] != mapping[ch] {
                return false
            }
            stack = stack[:len(stack)-1] // 弹出栈顶
        }
    }
    
    return len(stack) == 0
}
```

**解题思路**：
1. 遇到左括号就入栈
2. 遇到右括号检查栈顶是否匹配
3. 最后栈应为空

### 2. 单调栈

**适用场景**：
- 寻找下一个更大/更小元素
- 柱状图中最大矩形
- 接雨水问题

**核心思想**：
- 维护一个单调递增或递减的栈
- 当新元素破坏单调性时，弹出栈顶并计算结果

#### 示例：每日温度（LeetCode 739）

```go
func dailyTemperatures(temperatures []int) []int {
    n := len(temperatures)
    result := make([]int, n)
    stack := []int{} // 存储索引
    
    for i, temp := range temperatures {
        // 当前温度高于栈顶索引对应的温度
        for len(stack) > 0 && temp > temperatures[stack[len(stack)-1]] {
            prevIndex := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            result[prevIndex] = i - prevIndex
        }
        stack = append(stack, i)
    }
    
    return result
}
```

**解题思路**：
1. 栈中存储索引，保持温度单调递减
2. 当遇到更高温度时，弹出栈顶并计算天数差
3. 未找到更高温度的位置保持为 0

#### 示例：柱状图中最大的矩形（LeetCode 84）

```go
func largestRectangleArea(heights []int) int {
    n := len(heights)
    stack := []int{} // 存储索引，保持高度单调递增
    maxArea := 0
    
    for i := 0; i <= n; i++ {
        // 处理边界：在最后添加高度 0
        currHeight := 0
        if i < n {
            currHeight = heights[i]
        }
        
        // 当前高度小于栈顶高度，计算面积
        for len(stack) > 0 && currHeight < heights[stack[len(stack)-1]] {
            height := heights[stack[len(stack)-1]]
            stack = stack[:len(stack)-1]
            
            width := i
            if len(stack) > 0 {
                width = i - stack[len(stack)-1] - 1
            }
            
            area := height * width
            if area > maxArea {
                maxArea = area
            }
        }
        stack = append(stack, i)
    }
    
    return maxArea
}
```

### 3. 表达式求值

**适用场景**：
- 逆波兰表达式求值
- 基本计算器
- 简化路径

#### 示例：逆波兰表达式求值（LeetCode 150）

```go
func evalRPN(tokens []string) int {
    stack := []int{}
    
    for _, token := range tokens {
        switch token {
        case "+", "-", "*", "/":
            b := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            a := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            
            var result int
            switch token {
            case "+":
                result = a + b
            case "-":
                result = a - b
            case "*":
                result = a * b
            case "/":
                result = a / b
            }
            stack = append(stack, result)
        default:
            num, _ := strconv.Atoi(token)
            stack = append(stack, num)
        }
    }
    
    return stack[0]
}
```

## 三、队列的常见题型

### 1. BFS（广度优先搜索）

**适用场景**：
- 二叉树层序遍历
- 最短路径问题
- 岛屿数量

**核心思想**：
- 使用队列实现层次遍历
- 每次处理一层节点

#### 示例：二叉树的层序遍历（LeetCode 102）

```go
func levelOrder(root *TreeNode) [][]int {
    if root == nil {
        return [][]int{}
    }
    
    result := [][]int{}
    queue := []*TreeNode{root}
    
    for len(queue) > 0 {
        levelSize := len(queue)
        currentLevel := []int{}
        
        for i := 0; i < levelSize; i++ {
            node := queue[0]
            queue = queue[1:]
            currentLevel = append(currentLevel, node.Val)
            
            if node.Left != nil {
                queue = append(queue, node.Left)
            }
            if node.Right != nil {
                queue = append(queue, node.Right)
            }
        }
        
        result = append(result, currentLevel)
    }
    
    return result
}
```

### 2. 滑动窗口最大值

**适用场景**：
- 固定窗口的最值问题
- 数据流中的中位数

**核心思想**：
- 使用双端队列维护窗口内的候选答案
- 队列保持单调性

#### 示例：滑动窗口最大值（LeetCode 239）

```go
func maxSlidingWindow(nums []int, k int) []int {
    result := []int{}
    deque := []int{} // 存储索引，保持值单调递减
    
    for i, num := range nums {
        // 移除队首超出窗口的元素
        if len(deque) > 0 && deque[0] <= i-k {
            deque = deque[1:]
        }
        
        // 移除队尾小于当前元素的索引
        for len(deque) > 0 && nums[deque[len(deque)-1]] < num {
            deque = deque[:len(deque)-1]
        }
        
        deque = append(deque, i)
        
        // 当窗口形成后，记录最大值
        if i >= k-1 {
            result = append(result, nums[deque[0]])
        }
    }
    
    return result
}
```

**解题思路**：
1. 双端队列存储索引，对应的值单调递减
2. 队首始终是当前窗口的最大值
3. 新元素进入时，移除所有比它小的元素

### 3. 优先队列（堆）

**适用场景**：
- Top K 问题
- 合并 K 个有序链表
- 任务调度

#### 示例：数组中的第 K 个最大元素（LeetCode 215）

```go
import "container/heap"

// 最小堆
type MinHeap []int

func (h MinHeap) Len() int           { return len(h) }
func (h MinHeap) Less(i, j int) bool { return h[i] < h[j] }
func (h MinHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }

func (h *MinHeap) Push(x interface{}) {
    *h = append(*h, x.(int))
}

func (h *MinHeap) Pop() interface{} {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[:n-1]
    return x
}

func findKthLargest(nums []int, k int) int {
    h := &MinHeap{}
    heap.Init(h)
    
    for _, num := range nums {
        heap.Push(h, num)
        if h.Len() > k {
            heap.Pop(h) // 保持堆大小为 k
        }
    }
    
    return (*h)[0] // 堆顶就是第 K 大元素
}
```

## 四、解题通用步骤

### Step 1: 识别问题类型
- 是否需要"后进先出"？ → 栈
- 是否需要"先进先出"？ → 队列
- 是否需要维护最值？ → 单调栈/优先队列
- 是否需要层次遍历？ → BFS + 队列

### Step 2: 选择数据结构
| 问题特征 | 推荐结构 |
|---------|---------|
| 括号匹配、表达式求值 | 栈 |
| 下一个更大元素 | 单调栈 |
| 层序遍历、最短路径 | 队列（BFS） |
| 滑动窗口最值 | 双端队列 |
| Top K 问题 | 优先队列（堆） |

### Step 3: 设计算法流程
- 明确何时入栈/入队
- 明确何时出栈/出队
- 明确如何维护单调性或优先级

### Step 4: 处理边界情况
- 空栈/空队列操作
- 栈溢出（虽然 Go 切片动态扩容）
- 队列长度控制

## 六、常见陷阱与注意事项

1. **栈空检查**：pop/peek 前检查栈是否为空
2. **队列空检查**：dequeue/front 前检查队列是否为空
3. **单调栈方向**：搞清楚是单调递增还是递减
4. **索引 vs 值**：单调栈通常存储索引而非值
5. **堆的实现**：Go 的 `container/heap` 是最小堆，需要自定义实现最大堆

## 七、Go 语言实用技巧

```go
// 1. 切片作为栈
stack := []int{}
stack = append(stack, 1)      // push
val := stack[len(stack)-1]     // peek
stack = stack[:len(stack)-1]   // pop

// 2. 切片作为队列（效率低，建议用 list）
queue := []int{}
queue = append(queue, 1)       // enqueue
val := queue[0]                 // front
queue = queue[1:]               // dequeue

// 3. 使用 container/list 实现高效队列
import "container/list"
q := list.New()
q.PushBack(1)                   // enqueue
val := q.Front().Value.(int)   // front
q.Remove(q.Front())             // dequeue

// 4. 双端队列操作
deque := []int{}
deque = append(deque, 1)       // 尾部添加
deque = append([]int{0}, deque...) // 头部添加
val := deque[0]                 // 头部访问
val = deque[len(deque)-1]      // 尾部访问
deque = deque[1:]              // 头部删除
deque = deque[:len(deque)-1]   // 尾部删除
```
