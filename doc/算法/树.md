# 树

## 一、基础概念

树是一种非线性数据结构，特点：
- **层次结构**：由节点和边组成，有根节点
- **递归定义**：每个子树也是一棵树
- **无环**：任意两个节点之间只有一条路径
- **常用遍历**：前序、中序、后序、层序

### 二叉树节点定义

```go
type TreeNode struct {
    Val   int
    Left  *TreeNode
    Right *TreeNode
}
```

### 树的类型
- **二叉树**：每个节点最多有两个子节点
- **二叉搜索树（BST）**：左子树 < 根 < 右子树
- **平衡二叉树**：左右子树高度差不超过 1
- **完全二叉树**：除最后一层外，其他层都是满的
- **满二叉树**：所有非叶子节点都有两个子节点

## 二、树的遍历

### 1. 深度优先搜索（DFS）

#### 前序遍历（根-左-右）

```go
// 递归法
func preorderTraversal(root *TreeNode) []int {
    result := []int{}
    var dfs func(node *TreeNode)
    dfs = func(node *TreeNode) {
        if node == nil {
            return
        }
        result = append(result, node.Val) // 根
        dfs(node.Left)                     // 左
        dfs(node.Right)                    // 右
    }
    dfs(root)
    return result
}

// 迭代法
func preorderTraversalIterative(root *TreeNode) []int {
    result := []int{}
    if root == nil {
        return result
    }
    
    stack := []*TreeNode{root}
    for len(stack) > 0 {
        node := stack[len(stack)-1]
        stack = stack[:len(stack)-1]
        
        result = append(result, node.Val)
        
        // 先右后左，保证左先处理
        if node.Right != nil {
            stack = append(stack, node.Right)
        }
        if node.Left != nil {
            stack = append(stack, node.Left)
        }
    }
    
    return result
}
```

#### 中序遍历（左-根-右）

```go
// 递归法
func inorderTraversal(root *TreeNode) []int {
    result := []int{}
    var dfs func(node *TreeNode)
    dfs = func(node *TreeNode) {
        if node == nil {
            return
        }
        dfs(node.Left)                      // 左
        result = append(result, node.Val)  // 根
        dfs(node.Right)                     // 右
    }
    dfs(root)
    return result
}

// 迭代法
func inorderTraversalIterative(root *TreeNode) []int {
    result := []int{}
    stack := []*TreeNode{}
    curr := root
    
    for curr != nil || len(stack) > 0 {
        // 一直向左走到底
        for curr != nil {
            stack = append(stack, curr)
            curr = curr.Left
        }
        
        // 处理当前节点
        curr = stack[len(stack)-1]
        stack = stack[:len(stack)-1]
        result = append(result, curr.Val)
        
        // 转向右子树
        curr = curr.Right
    }
    
    return result
}
```

**重要性质**：BST 的中序遍历是有序数组

#### 后序遍历（左-右-根）

```go
// 递归法
func postorderTraversal(root *TreeNode) []int {
    result := []int{}
    var dfs func(node *TreeNode)
    dfs = func(node *TreeNode) {
        if node == nil {
            return
        }
        dfs(node.Left)                      // 左
        dfs(node.Right)                     // 右
        result = append(result, node.Val)  // 根
    }
    dfs(root)
    return result
}
```

### 2. 广度优先搜索（BFS / 层序遍历）

```go
func levelOrder(root *TreeNode) [][]int {
    if root == nil {
        return [][]int{}
    }
    
    result := [][]int{}
    queue := []*TreeNode{root}
    
    for len(queue) > 0 {
        levelSize := len(queue)
        currentLevel := []int{}
        
        for i := 0; i < levelSize; i++ {
            node := queue[0]
            queue = queue[1:]
            currentLevel = append(currentLevel, node.Val)
            
            if node.Left != nil {
                queue = append(queue, node.Left)
            }
            if node.Right != nil {
                queue = append(queue, node.Right)
            }
        }
        
        result = append(result, currentLevel)
    }
    
    return result
}
```

## 三、常见题型分类

### 1. 二叉搜索树（BST）

**适用场景**：
- 验证 BST
- 在 BST 中查找
- BST 的插入和删除
- BST 的第 K 小元素

**核心性质**：
- 左子树所有节点 < 根节点 < 右子树所有节点
- 中序遍历得到有序序列

#### 示例1：验证二叉搜索树（LeetCode 98）

```go
func isValidBST(root *TreeNode) bool {
    return helper(root, math.MinInt64, math.MaxInt64)
}

func helper(node *TreeNode, lower, upper int) bool {
    if node == nil {
        return true
    }
    
    // 当前节点必须在 (lower, upper) 范围内
    if node.Val <= lower || node.Val >= upper {
        return false
    }
    
    // 左子树的上界是当前节点值，右子树的下界是当前节点值
    return helper(node.Left, lower, node.Val) && 
           helper(node.Right, node.Val, upper)
}
```

**解题思路**：
1. 每个节点都有一个有效范围
2. 左子节点的上界是父节点值
3. 右子节点的下界是父节点值

#### 示例2：BST 中的第 K 小元素（LeetCode 230）

```go
func kthSmallest(root *TreeNode, k int) int {
    count := 0
    result := 0
    
    var inorder func(node *TreeNode)
    inorder = func(node *TreeNode) {
        if node == nil || count >= k {
            return
        }
        
        inorder(node.Left)
        
        count++
        if count == k {
            result = node.Val
            return
        }
        
        inorder(node.Right)
    }
    
    inorder(root)
    return result
}
```

**解题思路**：
- BST 中序遍历是有序的
- 第 K 个访问的节点就是第 K 小

### 2. 树的属性计算

**适用场景**：
- 树的最大深度
- 树的直径
- 平衡二叉树判断
- 完全二叉树节点数

#### 示例1：二叉树的最大深度（LeetCode 104）

```go
func maxDepth(root *TreeNode) int {
    if root == nil {
        return 0
    }
    
    leftDepth := maxDepth(root.Left)
    rightDepth := maxDepth(root.Right)
    
    return max(leftDepth, rightDepth) + 1
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```

#### 示例2：平衡二叉树（LeetCode 110）

```go
func isBalanced(root *TreeNode) bool {
    return height(root) != -1
}

func height(node *TreeNode) int {
    if node == nil {
        return 0
    }
    
    leftHeight := height(node.Left)
    if leftHeight == -1 {
        return -1
    }
    
    rightHeight := height(node.Right)
    if rightHeight == -1 {
        return -1
    }
    
    if abs(leftHeight-rightHeight) > 1 {
        return -1
    }
    
    return max(leftHeight, rightHeight) + 1
}

func abs(x int) int {
    if x < 0 {
        return -x
    }
    return x
}
```

**解题思路**：
- 自底向上计算高度
- 如果某节点不平衡，返回 -1
- 避免重复计算，时间复杂度 O(n)

### 3. 路径问题

**适用场景**：
- 路径总和
- 二叉树中的最大路径和
- 从根到叶子的数字之和

#### 示例1：路径总和（LeetCode 112）

```go
func hasPathSum(root *TreeNode, targetSum int) bool {
    if root == nil {
        return false
    }
    
    // 到达叶子节点
    if root.Left == nil && root.Right == nil {
        return root.Val == targetSum
    }
    
    // 递归检查左右子树
    remaining := targetSum - root.Val
    return hasPathSum(root.Left, remaining) || 
           hasPathSum(root.Right, remaining)
}
```

#### 示例2：二叉树中的最大路径和（LeetCode 124）

```go
func maxPathSum(root *TreeNode) int {
    maxSum := math.MinInt32
    
    var maxGain func(node *TreeNode) int
    maxGain = func(node *TreeNode) int {
        if node == nil {
            return 0
        }
        
        // 递归计算左右子树的最大贡献值
        leftGain := max(maxGain(node.Left), 0)
        rightGain := max(maxGain(node.Right), 0)
        
        // 当前节点作为最高点的路径和
        priceNewpath := node.Val + leftGain + rightGain
        
        // 更新全局最大值
        maxSum = max(maxSum, priceNewpath)
        
        // 返回当前节点的最大贡献值
        return node.Val + max(leftGain, rightGain)
    }
    
    maxGain(root)
    return maxSum
}
```

**解题思路**：
1. 对于每个节点，计算经过该节点的最大路径和
2. 路径可以是左子树 → 当前节点 → 右子树
3. 但返回给父节点的只能是单边路径

### 4. 树的构建与转换

**适用场景**：
- 从前序和中序遍历构造二叉树
- 将有序数组转换为 BST
- 二叉树展开为链表

#### 示例：从前序与中序遍历序列构造二叉树（LeetCode 105）

```go
func buildTree(preorder []int, inorder []int) *TreeNode {
    if len(preorder) == 0 {
        return nil
    }
    
    // 前序遍历的第一个元素是根节点
    rootVal := preorder[0]
    root := &TreeNode{Val: rootVal}
    
    // 在中序遍历中找到根节点的位置
    mid := 0
    for i, val := range inorder {
        if val == rootVal {
            mid = i
            break
        }
    }
    
    // 递归构建左右子树
    root.Left = buildTree(preorder[1:mid+1], inorder[:mid])
    root.Right = buildTree(preorder[mid+1:], inorder[mid+1:])
    
    return root
}
```

**解题思路**：
1. 前序遍历的第一个元素是根
2. 在中序遍历中找到根的位置，左边是左子树，右边是右子树
3. 根据左右子树的大小，在前序遍历中划分左右子树
4. 递归构建

### 5. 最近公共祖先（LCA）

**适用场景**：
- 二叉树的最近公共祖先
- BST 的最近公共祖先

#### 示例：二叉树的最近公共祖先（LeetCode 236）

```go
func lowestCommonAncestor(root, p, q *TreeNode) *TreeNode {
    if root == nil || root == p || root == q {
        return root
    }
    
    left := lowestCommonAncestor(root.Left, p, q)
    right := lowestCommonAncestor(root.Right, p, q)
    
    // p 和 q 分别在左右子树
    if left != nil && right != nil {
        return root
    }
    
    // p 和 q 都在左子树或右子树
    if left != nil {
        return left
    }
    return right
}
```

**解题思路**：
1. 如果在当前节点找到 p 或 q，返回当前节点
2. 递归查找左右子树
3. 如果左右都找到，说明当前节点是 LCA
4. 如果只在一侧找到，返回那一侧的结果

## 四、解题通用步骤

### Step 1: 确定遍历方式
| 问题类型 | 推荐遍历 |
|---------|---------|
| 复制/序列化树 | 前序遍历 |
| BST 排序/查找 | 中序遍历 |
| 释放/删除树 | 后序遍历 |
| 层次相关操作 | BFS/层序遍历 |

### Step 2: 选择递归或迭代
- **递归**：代码简洁，适合大多数情况
- **迭代**：避免栈溢出，需要显式维护栈/队列

### Step 3: 设计递归函数
1. **终止条件**：通常是 `node == nil`
2. **返回值**：明确返回什么（高度、布尔值、节点等）
3. **单层逻辑**：处理当前节点，递归处理子节点

### Step 4: 处理边界情况
- 空树
- 只有一个节点
-  skewed tree（退化成链表）

## 六、常见陷阱与注意事项

1. **空指针检查**：访问节点前先检查是否为 nil
2. **递归终止条件**：确保递归能够正确终止
3. **返回值设计**：明确递归函数应该返回什么
4. **BST 的边界**：验证 BST 时要注意是严格小于/大于
5. **修改原树**：注意题目是否允许修改原树结构

## 七、Go 语言树的技巧

```go
// 1. 创建节点
node := &TreeNode{Val: 1}

// 2. 连接节点
node.Left = &TreeNode{Val: 2}
node.Right = &TreeNode{Val: 3}

// 3. 辅助函数
func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}

func abs(x int) int {
    if x < 0 {
        return -x
    }
    return x
}

// 4. 打印树（调试用）
func printTree(root *TreeNode, prefix string, isLeft bool) {
    if root == nil {
        return
    }
    
    fmt.Printf("%s%s%d\n", prefix, map[bool]string{true: "├── ", false: "└── "}[isLeft], root.Val)
    
    newPrefix := prefix + map[bool]string{true: "│   ", false: "    "}[isLeft]
    printTree(root.Left, newPrefix, true)
    printTree(root.Right, newPrefix, false)
}
```

1. **理解三种 DFS 遍历**：前序、中序、后序的应用场景
2. **熟练运用递归**：树的问题大多用递归解决
3. **掌握 BST 性质**：中序遍历有序，查找高效
4. **学会画图分析**：帮助理解递归过程
5. **背诵经典模板**：遍历、LCA、路径和等
